Will not

What this desk will not file.

A refused instruction is cheaper than a report we cannot defend. If the asset or the act is on this list, the file stays closed.

Refused on cover

Will notFile

Returned unopened. No fee is raised. Ask first if the asset is not listed — the file still may not open.

Asset

Will not value

  • Jewellery, art, or movable collections (except listed plant)
  • Going-concern businesses without a property instruction
  • Assets outside India
  • Hypothetical FSI that has no sanctioned plan
Act

Will not do

  • Guaranteed bank sanction letters
  • Back-dated opinions
  • Structural design or soil testing
  • Marketing a property for sale

Brief anatomy

How an instruction is read.

Four fields on the jacket before anyone travels. If a field is blank, the file does not open.

InstructionSPV · Four fieldsBefore travel

  1. 01

    Written first

    Purpose

    Mortgage, sale, insurance, litigation, IBC-related (demo).

  2. 02

    On the jacket

    Asset

    Class, city, carpet / built-up, occupancy.

  3. 03

    Named

    Users

    Named client and any lender. No unnamed “the market”.

  4. 04

    On the invoice

    Fee

    Starting line, GST extra, rush surcharge if dated.

If all four are written, the slot can be booked.
